pi 仓库术语表（Glossary）

压缩的速查文档 · 之后所有 lesson 都以此词汇表为准（glossary 是权威，别词）

项目与仓库

术语含义
pi / Pi Agent Harness项目总称：一个极简的终端 AI 编程代理 harness（本仓库）。
pi-monorepo根 package.json 里 workspaces 字段声明的包集合。
monorepo一个 git 仓库管理多个 package；本仓库用 npm workspaces 链接本地包。
npm workspaces让 PI/packages/* 里的包互相引用时用本地源码，不重复安装。

包（构建顺序：从底到顶）

包一句话职责
@earendil-works/chord应用组合运行时：services、复制状态、RPC、插件。
@earendil-works/pi-tui终端 UI 库（差分渲染）。
@earendil-works/pi-telemetry供应商中立的遥测契约与参考实现。
@earendil-works/pi-ai统一多供应商 LLM API（OpenAI、Anthropic、Google…）。
@earendil-works/pi-agent-coreagent 运行时：主循环、工具调用、会话状态管理。
@earendil-works/pi-session-backends-*会话持久化后端（如 sqlite-node）。
@earendil-works/pi-protocol客户端与服务器之间 JSONL RPC 协议定义。
@earendil-works/pi-clientRPC 客户端（连到 server）。
@earendil-works/pi-serverRPC 服务器（跑 agent 会话）。
@earendil-works/pi-coding-agent交互式编程代理 CLI，也就是 pi 命令（产品面）。
evalsbenchmark / 评估测试包（不在主链路）。

核心概念

术语含义
agent loop（主循环）模型决策 → 工具调用 → 观察结果 → 继续，直到任务完成。
tool（工具）agent 可执行的操作：读文件、写文件、跑 bash 等。
session（会话）一次对话从创建到结束的工作区状态；可保存、恢复、分支。
provider（供应商）对某一家 LLM API 的适配（鉴权、请求/响应转换）。
extension（扩展）用 TypeScript 写的可加载模块（工具、命令、事件、自定义 UI）。
skill可复用能力包（以 SKILL.md 声明的按需技能）。
prompt template由斜杠命令展开的复用提示模板。
TUITerminal User Interface，终端用户界面。
LLM大语言模型。
JSONL每行一个 JSON 对象的文本格式；session 文件和 RPC 流都用它。
model catalog（模型目录）ai 包维护的模型元数据（models.generated.ts，生成文件，勿手改）。
