Prerequisites Series

学习 PI 之前：7 门前置知识课

每课 8–15 分钟 · 全部锚定 PI 仓库真实代码 · 按重要度排序

这组前置课不是泛泛的入门教程——每一个概念都用 PI 项目里的真实代码片段来解释。学完后再去看 PI 的 agent loop、tool 系统、TUI，不会被语言细节绊住。

课程地图

优先级课程为什么要学
★★★★★ 01 · TypeScript 核心 项目 100% TS，大量泛型、类型守卫、接口、条件类型、可辨识联合
★★★★★ 02 · async/await 与 Promise Agent Loop 完全异步，流式响应基于 async iterator
★★★★ 03 · Node.js 事件与 Stream TUI 读 stdin 流，LLM 响应是 SSE 流，事件总线用 EventEmitter
★★★★ 04 · LLM API 概念 理解 streaming、tool calling、context window、reasoning
★★★ 05 · Git 克隆仓库、切换分支、看 diff、看日志
★★ 06 · npm & Monorepo workspaces 管理 10+ 包的依赖与构建顺序
★★ 07 · 终端基础 ANSI 转义码、raw mode、stdin/stdout，理解 TUI 怎么画屏

学习建议

  1. 从 ★★★★★ 开始，两门课学完再进入 PI 主系列，基本不会被语言卡住
  2. 每节课都有 3 道自测题（即时反馈），做完再进下一门
  3. ★★★★ 与 ★★★ 按需穿插：读 PI 某段代码遇到陌生概念，直接跳到对应章节查
  4. ★★ 的两门可以通读一遍建立"知道有这回事"的印象，用到时再回来细看
